# Business Stock ManagerA responsive, no-build inventory and sales tracker starter for a small business.## Included features- Dashboard with products, stock value, today's sales and estimated gross profit- Product create/edit/delete- Purchase entries that increase stock- Sales entries that reduce stock and prevent selling more than available quantity- Low-stock alerts- Sales, purchases and product CSV exports- JSON backup and restore- PKR currency formatting- Mobile-friendly layout## Run locallyOpen `index.html` in a modern browser. No installation or build step is required.## Deploy freeYou can publish this static website with GitHub Pages:1. Push all project files to the repository's root.2. Open the repository's **Settings → Pages**.3. Under Build and deployment, select **Deploy from a branch**.4. Select the `main` branch and `/ (root)`, then Save.5. Wait for GitHub Pages to publish the site; the URL will appear in the Pages settings.## Important data limitationThis starter stores data in the browser's local storage on the current device/browser. It does **not** have user accounts, a cloud database, multi-device sync, or server-side security. Export a JSON backup regularly. For multiple staff or devices, connect a backend/database before using it as the business's only record system.## Accounting notesGross profit is estimated using the purchase cost stored for each product. Purchase entries update the product's current cost, so this is a starter tracker rather than a formal accounting system. Expenses, taxes, customer credit, supplier balances and returns are not included yet.
